# 分析、AI 与解释边界

## 真实数据链

分析服务先按调用者的组织、组织单元、项目或本人 scope 构造数据库查询条件，再按时间窗口计算总工时、已批准/待审工时、日趋势、成员和项目分布。前端 ECharts 图表只消费这个 API 的聚合结果；空状态保持为空，不填充演示数字。

当前看板提供总量指标、按日趋势和项目分布；团队活动只返回可项目公开的记录。所有聚合的时区来自组织设置，时间边界使用服务端传入的 ISO 时间，避免浏览器本地时区混入工资或报表计算。

## AI 的职责

AI 请求只能使用已经完成权限过滤的聚合输入。后台任务记录请求范围、提示词模板版本、模型、输入哈希、任务状态、来源实体和生成时间；报告会标明来源数量。AI 输出是辅助解释，不会写入工时、审批、工资、角色或薪资规则，也不能代替管理或人事决定。

若 `AI_ENABLED=false`、模型请求超时或后台 worker 不可用，记录、计时、审批、工资和报表仍然可用。重试有次数上限；失败会保留任务错误摘要而不伪造完成报告。

## 解释性与导出

可解释的管理结论应同时显示时间范围、scope、样本数量、公式或规则版本、排除条件和来源链接。CSV 导出创建审计事件、记录字段策略及 SHA-256，并只包含调用者可见范围；完整内容字段需要对应的全范围授权。任何导出的报表均应注明生成时间、时区和筛选条件。
