# 2026-09-09 桌面与移动端验收记录

本轮检查针对仓库当前提供的功能，包括前期提出的附件提交、手机进度更新，以及员工加入项目并认领任务。检查采用源代码追踪、数据库集成测试、浏览器交互测试、真实 HTTP 业务链路、页面尺寸断言与截图检查。测试通过仅证明下列环境和用例，不代表穷尽所有设备、数据规模或外部服务故障。

## 修复内容

- 文件上传与完成核验分开记录。核验暂时失败时只重试完成接口，保留工作草稿和当前页面待处理文件，避免重建工时或重复登记附件。未核验、失败、隔离状态不能显示成功或充当可提交证据。
- 两个完成核验请求并发时，第二个请求重新读取已提交的状态，避免文件实际可用却返回旧的 pending_upload；不重复生成完成审计与通知事件。数据库集成测试已复现并覆盖该竞态。
- 添加工作记录时，手机端可通过大尺寸进度滑条、数字输入和百分比快捷键更新完成度。主关联为自动汇总节点时，可选择其中可手工更新的任务节点。
- 普通员工加入项目后，可认领尚无负责人的任务节点；服务端检查组织、项目成员身份、项目及分支状态、节点版本，保留协作者，禁止抢占他人负责的节点，并产生审计与同步事件。
- 中文附件预览与下载的 Content-Disposition 改为 ASCII 后备名称和 UTF-8 编码名称，避免严格 HTTP 实现拒绝包含原始中文的响应头。
- 计时器暂停、继续、休息、结束休息和结束操作在请求与刷新期间禁用，防止连续触摸产生相互冲突的状态请求。
- 项目工作区去除嵌套 main 地标，保留唯一页面主区域与命名的项目区域。
- 显式将共享 UI 组件加入 Tailwind 扫描，修复正式包缺失紧凑按钮尺寸等样式的问题；加入项目按钮、手机日历日期/筛选和触摸设备上的分析项目筛选按钮提供至少 44px 高度。
- 浏览器用例等待登录完成再跳转，避免导航取消尚未完成的登录请求；增加请求处理中按钮不可操作的断言。

## 真实 HTTP 与数据库链路

`apps/server/test/live-server.ts` 使用完整数据库迁移创建内存 PGlite 数据库，启动正式 Fastify 路由和构建后的前端。文件服务仅在本机监听，实际接收 PUT 字节，供正式对象存储适配器执行 HEAD、GET 和 SHA-256 核验。测试没有拦截或模拟业务 API，也不会连接环境变量中的生产数据库。

每个浏览器配置均执行：

1. 管理者登录、创建一次性邀请；员工激活并登录，确认没有项目管理权限且审批 API 返回 403。
2. 管理者创建项目/任务与员工薪资方案；员工通过页面加入项目并认领任务，数据库读取核对归属。
3. 员工在页面上传真实 PNG 字节、保存工作记录并汇报 75% 进度；通过正式 API 确认证据 available、节点完成度更新。
4. 员工提交审核；管理者在页面打开证据、批准；下载的中文文件与原始 PNG 逐字节一致；员工看到已批准，薪资预估与搜索读取同一工作记录。
5. 员工提交缺少凭证的报销得到明确错误；添加文字凭证后提交，管理者批准并指定薪资周期；计算结果包含 128.35 元报销，撤销计算恢复开放周期；报销流程不会新增工时。
6. 员工通过页面依次开始、暂停、继续、休息、结束休息、结束计时，验证实际生成正时长的计时记录。
7. 创建未来计划前后，真实工时分析汇总不变；CSV 导出包含已完成工作，不包含未来计划。
8. 管理者 14 个页面、员工 11 个页面逐一加载，检查主区域、加载完成、水平溢出、页面脚本异常和业务 API 500，输出控件 JSON 与截图。

## 复验命令与产物

```sh
pnpm check
pnpm exec playwright install chromium firefox webkit
pnpm test:e2e
pnpm test:live
```

- `pnpm check`：lint、TypeScript、单元/集成测试与全部应用构建。本轮 186 项测试通过。
- `pnpm test:e2e`：桌面 Chromium 与移动 Chromium 的交互契约测试。本轮 159 项通过，9 项因仅适用于另一种设备而按预先声明跳过，没有用跳过掩盖失败。
- `pnpm test:live`：Chromium 360×800、390×844、768×1024、1440×900、1920×1080；另开隔离环境运行 Firefox 桌面与 iPhone 13 配置的 WebKit。7 项真实业务链路通过，覆盖 175 个页面/身份/浏览器组合，输出 175 份截图及 3,799 条当次可见控件实例记录（不是 3,799 个独立功能）。
- `test-results/live`、`test-results/engines`：各配置的整页 PNG 与 `rendered-controls.json`。GitHub Actions 的 `workspace-acceptance-<run-id>` 保存此类产物 7 天；失败时另保留诊断轨迹。仅含隔离测试数据。

## 验证边界

- PGlite 验证真实 SQL/事务与业务数据链路；PostgreSQL CI 迁移门禁仍保留。没有将本次轻量验收当作高并发、多进程锁竞争、生产容量压测或灾难恢复演练。
- 本地对象存储夹具不验证云供应商签名策略、生产桶 CORS/权限/配额；必须区别“代码实际上传和下载通过”与“生产 B2 配置经过实测”。
- AI 供应商、邮件/SMS、浏览器 Push 的生产凭据、网络与实际投递不属于本地通过结论；相关权限、失败状态和 Worker 单元/集成检查仍执行。未向真实员工发送测试消息。
- WebKit 的手机配置是浏览器引擎与视口仿真，不能替代 iPhone 真机、系统相册/相机、微信内置浏览器、系统键盘、安全区域和 PWA 安装的实机专项验收。
- 原设计中尚未实现的扩展能力仍按 `docs/design-coverage.md` 标注。当前功能检查不将路线图项目改写为已交付。
