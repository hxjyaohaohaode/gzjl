# 体验、异常恢复、AI 与图表深度优化验收（2026-09-21—22）

本轮以现有工作台的实际使用链路为范围，完成前端、API 和 AI Worker 的问题修复，并执行整个仓库的检查与回归。设计覆盖矩阵中的未完成产品能力仍按原状态记录，不以新增兜底或测试替代功能交付。

## 实际修复

| 领域 | 原有问题 | 当前行为 |
| --- | --- | --- |
| 网络与请求 | 多层重试放大等待时间；成功状态的 HTML 错误页可能变成渲染异常；并发写入重复获取 CSRF | 安全读取有限重试，权限等永久错误不重试；请求和响应体有超时；写入不自动重复；CSRF 握手合并且旧会话响应失效；错误提供重新加载或核对结果的下一步 |
| 页面恢复 | 读取失败被展示成无记录、无计时或零值；偏好存储受限可能使整个工作台无法显示 | 首页、工时、项目、审批、日历、薪资、报销、组织、分析及 AI 增强错误状态；可重试读取；增加页面与根级错误边界；浏览器存储失败保留内存中的界面设置 |
| 离线计时与本机草稿 | 队列没有明确账号归属和同步反馈；切换账号有误重放风险；冲突时缺少处理出口 | 新事件按 membershipId 隔离，服务端核对发送账号；只重放本人队列，重用事件编号；事务提交成功才报告本机保存成功；显示待同步数量、错误和手工重试；冲突可查看操作并确认放弃已列出的本机事件；本机预填写也按账号隔离 |
| 退出与浏览器推送 | 退出失败仍跳转登录页；迟到的身份查询可能恢复旧账号；推送准备与解绑可能长时间阻塞 | 服务端确认退出或返回会话失效后才清除身份；失败显示重试入口；取消旧查询；登录重新读取身份；推送 Worker 准备限时 10 秒，退出前清理限时 3 秒，迟到的浏览器查询不继续解绑后续账号 |
| 工时录入 | 清空结束时间导致渲染异常；追加工作段受设备时区影响；保存期间仍可修改即将被清空的表单 | 不完整时间保持可编辑，不误判为事实或计划；追加段按组织时区续接；保存期间禁用编辑和收起，失败后恢复并保留草稿 |
| 通知反馈 | 读取失败无主动重试；标已读失败缺少反馈，多种状态操作可并发 | 读取与写入分别展示错误；保留上次读取的通知；未读数未知时明确说明；提供重新加载，状态操作互斥且失败可重试 |
| AI 对话与报告 | 提交返回时清空后来编辑的文本或其他对话的草稿；长期打开页面使用过时报告区间；迟到的任务创建跳回旧对话；通知故障影响报告完成 | 按对话保留草稿，响应只清除本次确实提交且未再编辑的文本；报告按操作时刻生成范围，仅在仍处于原页面状态时选择返回任务；页面 Copilot 可取消任务；历史与来源读取可重试；通知异常不回滚已完成报告或触发重复供应商调用 |
| 图表 | 自定义提示文本未转义；手机样式可能残留到桌面；全屏不受支持时没有有效替代；缺少可读数据 | 转义自定义 HTML 提示；完整替换配置并保留缩放和图例选择；尊重减少动画设置；提供主要系列的数据表、缺失值和独立单位；PNG 导出反馈；全屏降级容器移到页面顶层，避免卡片裁剪、侧栏和其他图表遮挡 |
| 日期与导出 | 日期范围跨午夜后不更新，固定毫秒减法不符合夏令时自然日；下载可能无限等待或把错误页当文件 | 分析区间依据组织时区自然日，在跨日或重新聚焦后更新；直接导出有超时、格式与非空校验及明确反馈；显示导出应用时间范围和权限、不会自动套用图表维度筛选 |
| 键盘与可访问名称 | 搜索、AI 面板和全屏缺少完整焦点管理；组织表单依赖占位文字 | 弹层 Tab / Shift+Tab 保持焦点，关闭返回触发控件；图表数据入口支持键盘；组织管理补齐输入框和选择框名称；加载和结果提供状态语义 |

## 自检中发现并补入回归的问题

- 不能只检查全屏容器尺寸。人工截图发现卡片的裁剪与层级使降级全屏被侧栏、相邻图表遮挡；增加页面四角及中心的实际命中检测，并在真实服务下的 Chromium、Firefox、WebKit 中验证。
- 新数据表会与原有薪资明细共享文字。薪资断言改为定位可见的明细段落，继续核对金额构成和确认收款链路。
- 跨午夜的日历夹具在周一将前半段放到了上一周。修正夹具保证两段都位于被验收的当前周，继续严格要求呈现两个片段。
- AI 通知偏好读取失败通过数据库集成测试验证：报告仍保持完成状态，来源与实时事件保留，供应商调用仅一次。
- 本机操作放弃测试同时检查取消确认和接受确认，避免误触即删除待同步操作。
- 控件巡检不将 select 的选项文字当作字段标签；为被巡检的表单字段检查可访问名称。组织管理补齐六处名称，薪资五种倍率将勾选框与数值框分开标记，禁用状态的数值框也保留名称。
- 续轮增加退出 503 后重试、401 已失效会话、迟到身份响应、推送准备/解绑超时与迟到回调测试；退出失败不会再被显示为成功。
- 续轮验证通知读取失败后恢复、状态写入失败后重试，未读数量不会在失败时被本地修改。
- 工时专项验证实际清空主段和追加段的日期，草稿内容保持；将组织时区设为 Honolulu、浏览器设为 Shanghai，核对追加段仍精确承接上一段结束时间；延迟保存再模拟失败，核对表单锁定与失败后的草稿恢复。
- AI 任务创建响应被延迟期间新建对话并输入草稿，响应返回后 URL 与草稿均保留在新对话。
- 用独立失败用例复现 AI 面板与 Ctrl+K 搜索同时捕获 Tab 的问题；搜索接管时关闭其他工具弹层并保留 AI 草稿，全屏图表期间不再打开被遮挡的搜索框。补入桌面、手机键盘回归及真实浏览器全屏检查。

## 验证边界与后续事项

- AI 配置服务和 Worker 使用真实实现，供应商响应由测试桩控制，覆盖超时、限流、鉴权、取消、重试、配置切换和完成竞态。本轮未用生产供应商密钥发起真实付费生成，不能据此认定生产供应商账号、网络及部署已经验收。
- 文件链路验证了真实上传、核验与下载字节；外部生产对象存储、生产 Push、邮件/SMS 及灾难恢复演练仍需对应环境验收。
- 无归属的旧版离线事件不会自动分配给当前账号或重放；其数据仍保留在原浏览器中。此策略优先避免跨账号误写，旧事件如需补录应先人工核对事实。
- 构建仍有现有的大模块体积提示，主要是页面入口和 ECharts 分包；本轮没有通过调高阈值隐藏该提示。更细的路由拆分和大数据量性能基准应单独推进。
- 逐字段离线合并、完整跨图框选联动、AI 修改建议确认链等未完成能力仍见 [全量设计覆盖矩阵](design-coverage.md)。本轮不将其标记为完成。
- 改动保留在当前工作区，本轮没有提交、推送或执行生产部署。
