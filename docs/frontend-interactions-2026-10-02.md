# 全站前端交互重构

## 产品依据

重新读取《工作时间与工作智能管理平台_Codex全量开发主提示词》、完整《全量产品与交互设计报告》、README、架构、设计覆盖矩阵和交互审计。核心目标是低摩擦记录真实工作，沿“成员 → 项目节点 → 工作记录与证据 → 审批 → 薪资 → 分析、AI、提醒”联动。前端交互必须基于真实请求与事实状态。

## 统一交互层

- `workspace-primitives.tsx` 独立承载标题、字段、空状态、加载和错误；页面标题显示任务说明，入口层级显示当前位置。
- `workspace-pages.ts` 保存全站页面目的与上级入口，页面跳转同步浏览器标题。
- `interaction-controller.ts` 为动态挂载的原生控件、共享组件、弹层、图表、指标与状态注册实例身份。点击、触屏、表单提交、字段校验与真实 mutation 状态关联；成功仅在请求及其成功回调完成后呈现。页面离开、并发和迟到结果不会把反馈标到其他编辑器。
- 指标变化只强调已到达的新事实值，不生成中间工资数字。组件状态只保留于浏览器内存，不采集输入、薪资、密码或请求正文，不发送分析埋点。
- `interaction-system.css` 独立维护动效时长、层级、按钮反馈、表单焦点、选择导航、弹层、折叠、列表、进度和实时值强调，避免继续把所有规则追加到原有大样式文件。
- 页面操作条显示真实并发请求状态；加载条无虚构百分比。现有业务错误和重试仍留在原操作区域。
- 外观设置提供“完整响应 / 减少动态”。系统减少动态优先，图表和 CSS/Motion 同步遵循；存储不可用时仍可在当前页面调整。
- 工作编辑器定位、AI 对话滚动与项目画布适应视图也读取同一动态偏好，避免只关闭 CSS 而继续移动画布。
- 单字段组件把字段名称与辅助说明分开：名称用于操作定位，说明由 `aria-describedby` 关联，保留原生表单校验与显式业务标签。
- 统一状态层不拦截业务点击、不代替权限或防重复提交、不改写服务端状态、不接管 Canvas 手势。

## 高频业务流程

- 薪资方案使用成员列表与编辑区联动；姓名、编号与方案检索，缺方案筛选，成员 URL 定位，同名成员显示编号。
- 未保存方案按账号和成员在内存中隔离；切换成员、管理页面可继续，刷新/关闭提醒。退出或账号变更清除，不长期缓存工资内容。实时版本变化显示冲突，迟到保存使用快照比较，不删除后来输入。
- 草稿以同步订阅驱动输入控件，复选框点击立即生效；保存捕获当时的成员与快照，浏览器后退后也只清理原成员草稿。新方案默认生效时间晚于已存在的未来版本。
- 周期与最新批次归入同一卡片，显示四步进度、当前状态、下一步及对应操作。已撤销新批次不会重新露出更早的可操作批次。
- 月份、状态、关键词共同筛选；进入交接和更新计算后保留原列表条件。
- 周期创建期间冻结字段并阻止重复提交；缺薪资方案可直接定位指定成员。

## 覆盖与验证

| 组件类别 | 关联的真实状态 | 响应 |
| --- | --- | --- |
| 页面与导航 | 当前 URL、角色允许入口 | 页面定位、标题、选中块平滑切换 |
| 按钮与表单 | 原生提交、校验、请求完成及失败 | 按压、焦点、当前区域处理轮廓与成功/错误反馈 |
| 弹层与详情 | 实际挂载、打开、关闭 | 轻量进入效果，保留既有焦点管理 |
| 指标、标签与进度 | 已返回的数据、真实进度 | 数值变化强调、进度过渡，不插值工资金额 |
| 图表、列表与折叠 | 筛选、键盘焦点、展开状态 | 表格行定位、面板展开、图表更新；缩放与已选项保持 |
| 薪资成员编辑器 | 成员编号、服务端版本、本地草稿 | 列表定位、冲突说明、错误保留、提交期间冻结 |
| 结算周期卡片 | 周期和最新批次 | 步骤、下一步、可执行操作同时更新 |

源码组件索引及入口统计由 [追踪清单](frontend-interaction-inventory.md) 自动生成。真实服务验收逐页检查管理员和员工页面，保存每个控件的标识、类型、标签与尺寸。业务状态、权限、草稿、错误、触屏、深色主题、减少动态与完整链路通过对应自动化测试验证；最终执行结果以本轮验收日志为准。
