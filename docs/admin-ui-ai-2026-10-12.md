# 2026-10-12 界面与 AI 配置升级

借鉴本机 `超高级管理后台` 的珍珠玻璃材质、语义色、密度和命令面板交互，将设计适配到现有 React 平台。业务布局、权限与工时、工资计算继续复用现有实现。

## 界面与操作

- `apps/web/src/admin-theme.css` 统一控制全站颜色、阅读面、导航玻璃、卡片、表单与浮层；其后导入 `reference-interactions.css` 补齐本轮参考组件响应与移动端适配。
- 外观设置新增舒适 / 紧凑密度，记忆本机选择。紧凑布局在桌面精确指针环境生效，手机继续保持原有触控尺寸。浅色、深色、跟随系统、强调色和动效设置继续可用。
- 命令面板使用 Ctrl / Command + K 打开，支持方向键选择、Enter 打开、Escape 关闭与焦点恢复；增加最近访问和外观快捷操作。最近访问按成员隔离，只保存页面路径，展示时再次过滤当前可见导航权限；业务搜索继续调用服务端授权接口。
- 顶栏显示所在模块和页面。Owner 导航新增 AI 模型配置入口。

## 模型配置

入口为 `/ai/settings`，也可从 AI 工作洞察的组织 AI 配置按钮进入。仅组织 Owner 可修改，服务端继续校验 Owner 身份、当前密码和已启用的 TOTP。

连接地址、任意模型标识、API Key、最大输出 Token、请求超时、尝试次数、温度、Top P、Token 参数、响应格式和每日 / 每月额度均可填写。兼容范围为 OpenAI Chat Completions 接口；模型名称按供应商实际标识填写，无内置模型名单限制。

供应商扩展参数为可选 JSON 对象，例如：

```json
{
  "reasoning_effort": "high",
  "thinking": { "type": "disabled" }
}
```

仅填写所选供应商支持的参数。扩展参数最多 24 个顶层字段、8192 字符、6 层嵌套；拒绝重复的受管字段、凭据与原型属性。API Key 只使用专门的加密字段。保留原事实提示词、非流式请求及单个结果约束。

保存期间锁定表单；发生更改后禁用旧配置测试，并提供保存并测试新配置。成功保存会清空页面中的 API Key、当前密码与动态码。扩展参数与既有参数一起保存到已有 `generation_options` JSONB 列，无需数据库迁移；旧配置自动使用空扩展对象。

连接测试与 Worker 共用供应商配置解析和请求体构建，所以地址、模型、密钥、Token 方言和扩展参数来自同一份当前配置。待处理任务在执行时读取当前配置；已经发送的供应商请求继续完成其原请求。

## 验证入口

- `pnpm check`：静态检查、类型检查、单元及集成测试、生产构建。
- `pnpm test:e2e`：桌面与手机浏览器交互回归。
- `pnpm exec playwright test -c playwright.upgrades.config.ts`：隔离数据库、正式 API 与构建前端验收；新增 AI 配置验收通过受控的供应商适配器检查请求，不向真实 AI 服务发请求，也不放宽连接地址校验。

共享参数测试覆盖可选零值、扩展 JSON、受管字段、凭据、大小、嵌套及旧配置；数据库集成与 Worker 测试验证保存后的参数实际发送。新增浏览器用例同时保存浅色 / 深色、首页 / 配置页 / 命令面板截图到 `test-results/e2e`。

初轮基线验证：静态检查与类型检查通过；440 项单元及集成测试通过；生产构建通过；Chromium 桌面与手机回归 323 项通过、9 项按设备条件跳过；隔离真实 API 验收 2 项通过。用户后续 25 条批注的适配内容和最终验收结果见 [参考组件响应与业务适配记录](reference-response-adaptation-2026-10-12.md)。
